# ローカル採用会議 スタジオ

ビデオポッドキャスト「ローカル採用会議」（地域企業の人材採用に関する課題と改善提案・新卒採用中心）の収録進行コンソールです。単一HTMLファイルのウェブアプリとして動作し、インストールやデータベースは不要です。

## ▶ アプリを開く

**[ここをクリックしてアプリを起動](./index.html)**

（リポジトリのPages URL: `https://ishuntarow-netizen.github.io/local-saiyo-studio/`）

推奨ブラウザ: **Chrome / Edge**（音声文字起こしを使用するため）

## 搭載機能（v6）

| パネル | 機能 |
|---|---|
| **① アジェンダ** | 項目ごとのタイマー管理、未完了3件のコンパクト表示、全画面表示、脱線メモへの退避・復帰、番号つきテキストからの一括作成 |
| **② 音声テキスト化** | マイク音声のリアルタイム文字起こし（ja-JP）、編集してAIへ送信、マイク録音（.webm保存）、ミュート（録音無音化＋認識一時停止） |
| **③ AI回答・回答選択** | 地域採用専用のAIキャストとの対話。3案の候補生成→採用でAI発言が確定、音声読み上げ（音声合成） |
| **④ Google検索** | Gemini APIのGoogle検索連動（grounding）で、要約＋出典つきの調査結果を表示。③への転記も可能 |
| **⑤ カメラ確認** | 本番前の映り・構図チェック用プレビュー（鏡表示切替つき） |
| **⑥ 音量メーター** | マイク入力レベルの可視化（録音・文字起こしの動作確認に） |

## 初期設定

1. アプリ右上の **⚙ 設定** を開く
2. **Gemini APIキー** を入力（[Google AI Studio](https://aistudio.google.com/) で無料取得）→ **接続テスト** で「✓ 接続OK」を確認 → 保存
3. カメラ・マイクの許可ダイアログで「許可」を選ぶ

- APIキーは **ブラウザ内（localStorage）にのみ保存** され、HTMLファイルには埋め込まれません。キーを含むファイルを公開しないでください
- 収録データ（アジェンダ・文字起こし・会話履歴）もブラウザごとに保存されます。持ち出すには **⬇ 書き出す** を使用
- AI機能はオンライン時のみ動作します（オフラインでは自動ロック、復帰で自動解除）

## 収録の流れ

1. ヘッダー左上の**収録ファイル名**を編集（書き出しファイル名になります）
2. **①テキストから一括作成** でアジェンダを反映（例：`1.どこで採用がとまっているか`）
3. **⑤カメラ確認** で映りチェック → **⑥音量メーター** でマイクの動作確認
4. ON AIRボタンで収録開始 → ②の文字起こし・録音と並行して③④でAIと対話
5. **⬇ 書き出す** で収録メモ（.txt）と音声（.webm）を保存

## 更新方法（リポジトリ管理者向け）

`index.html` を新しい版に差し替えてCommitするだけで反映されます（Pagesの再デプロイは1〜2分）。

## 技術メモ

- 単一ファイル構成（HTML/CSS/JSすべて内蔵・外部ライブラリ不要）
- 外部API: Gemini API（`gemini-2.5-flash` / `2.5-pro` / `2.5-flash-lite` を設定で切替、Google検索grounding対応）
- 音声認識: Web Speech API / 録音: MediaRecorder / 読み上げ: SpeechSynthesis（いずれもブラウザ標準機能）
